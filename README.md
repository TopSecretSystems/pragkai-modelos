# PRAGKAI · hoja de modelos locales

`hoja.json` es la lista de modelos locales que PRAGKAI ha medido con trabajo de verdad, y el
recomendado para cada tipo de equipo. La aplicación la lee una vez al día como mucho, al abrir
Modelos.

Va **firmada** (Ed25519) y la clave pública viaja dentro de PRAGKAI: una hoja que no casa con su
firma se ignora entera, y una más vieja que la que ya se tiene, también. Sin hoja, PRAGKAI usa la
lista que trae su versión.

Aquí no hay nada más que la hoja.
